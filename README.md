# RouteGuard

Cross-Chain Security Intelligence Platform

## Goal
Help users evaluate cross-chain transfer routes, understand potential risks, compare estimated fees, and track transactions.

## MVP Features
- Route comparison
- Explainable risk analysis
- Wallet connection
- Transaction tracking
- Security alerts
- Demo mode clearly labelled
- Responsive dashboard

## Security
- Never request or store seed phrases.
- Never claim simulated checks are live.
- Validate all user inputs.
- Require explicit user approval for wallet transactions.
